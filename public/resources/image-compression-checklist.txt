Image Compression Checklist (Web + Exam Portals)

1) Target size
- Photos: 50 KB to 200 KB (web)
- Government forms: 20 KB to 50 KB (verify portal)

2) Format choice
- Web: WebP preferred, JPEG fallback
- Documents: JPEG for photos, PNG for signatures

3) Dimensions
- Use minimum required dimensions
- Do not upscale a small image

4) Quality setting
- JPEG quality 80-90 for web
- JPEG quality 60-80 for strict size limits

5) Final verification
- Open image and confirm readability
- Check file size before upload
